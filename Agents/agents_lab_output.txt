                 right if right is free' cannot distinguish a

ALGORITHM COMPARISON ON THE SAME MAP
======================================================================
Strategy     Moves    Cells expanded   Shortest?
BFS             20                59         yes
DFS             22                34          no
A*              20                23         yes

BFS and A* both return a shortest path because every move costs the
same and the Manhattan heuristic never overestimates the distance
remaining. DFS returns a valid but longer path, because it commits
to one branch and only backtracks when it gets stuck. A* reaches
the same answer as BFS while expanding fewer cells, since it
prefers cells that appear to lead towards the goal.

======================================================================
THINK ABOUT IT - WHAT IF THE WAREHOUSE DOUBLES IN SIZE?
======================================================================
Scale           Grid   Free cells   Moves   BFS expanded   A* expanded
x1              7x21           66      20             59            23
x2             14x42          264      40            237            80
x4             28x84         1056      80            935           296

Doubling each side multiplies the number of cells by about four, and
the cells BFS expands grows in proportion, because BFS explores
essentially the whole reachable area before it happens to reach the
goal. The strategy stays correct but stops being economical.
A* expands far fewer cells at every size, and its advantage widens
as the map grows, which is the practical reason to prefer an
informed search once the warehouse is large.

Further difficulties at larger scale: memory, since BFS must hold
the whole frontier and visited set; other vehicles, which make the
environment dynamic so a single plan computed once goes stale;
and turning or acceleration costs, which break the assumption that
every move costs the same and so require a weighted search.
